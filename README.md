## 特色功能

- **美观GUI**：用户界面采用Material3主题，并且UI全部由真人设计，符合人类使用习惯
- **可扩展性强**：扁平化设计，单个应用的所有规则都放在一个文件夹内，可扩展性强
- **自动策略**：通过图形化编程创建自动策略，或者是直接让AI进行创建自动策略
- **命令行**：专为AI清理使用的命令行，提供多种筛选条件以及内置的规则，尽可能降低AI误删的风险（实验性功能，见 [wiki/CLI-Usage.md](wiki/CLI-Usage.md)）
