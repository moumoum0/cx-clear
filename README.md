## 主要功能

- **垃圾扫描**：扫描 Codex、Claude Code、Cursor 的本地缓存与残留文件
- **手动清理**：按照时间、大小等分类自行清理
- **清理策略**：支持创建复杂的策略对对话历史进行清理
